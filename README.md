# Plataforma de Capacitación en Ciberseguridad para PYMES

Proyecto académico del Semillero de Investigación de la Universidad Compensar.

Este piloto busca ofrecer un entorno interactivo para que las pequeñas empresas aprendan
conceptos básicos de seguridad digital y cómo actuar ante posibles ciberataques.

## Tecnologías
- React + SASS
- HTML + CSS
- GitHub Pages (Despliegue)

## Estructura general
- **frontend/** → interfaz de usuario
- **backend/** → espacio reservado para conexión con base de datos PostgreSQL
- **tests/** → pruebas básicas de interacción

Desarrollado por el equipo del Semillero de Investigación UCompensar.
